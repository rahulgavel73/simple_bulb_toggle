# 💡 Light Bulb Toggle

A simple light bulb that turns on and off with a button click, with a click sound effect. Built while learning DOM manipulation in JavaScript.

# Live Link
 https://rahulgavel73.github.io/simple_bulb_toggle
## Features

- Click the button to switch the bulb **On** and **Off**
- The button text and color change with the bulb's state
- A click sound plays on every press
- Responsive layout (the bulb resizes on smaller screens)

## Built With

- HTML
- CSS (Flexbox, hover effects, media queries)
- JavaScript (DOM)

## What I Learned

- Selecting elements with `document.querySelector()`
- Handling clicks with `addEventListener()`
- Changing styles with `element.style`
- Changing text with `innerText`
- Using a `let` variable (`flag`) to track on/off state
- Playing sounds with the `Audio` object
- Using `const` for values that never get reassigned
